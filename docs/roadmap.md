# Roadmap

Proposals; not implemented.

## App

- Isolate endpoint enumeration failures.
- Show pending devices and allow explicit removal of obsolete recovery entries.
- Report applied state and controller health.
- Test more Windows versions, display scales and sleep/reconnect cases.
- Add output profiles and timer extensions.
- Add optional silent expiry notices.
- Add schedules with manual overrides.
- Add explicit call and recording integrations.
- Sign releases and support package managers.

## Automation

- Session tokens: prevent one client from ending another session.
- Request IDs: make retries idempotent.
- Local events: report session, timer and restoration changes.
- MCP adapter: status, start, extend and restore.
- Read-only compatibility and device checks.

## Excluded

Cloud accounts, activity monitoring, notification contents, audio recording and automatic microphone muting.
